## 🚀 Getting Started

Clone the repo:

```bash
git clone https://github.com/Asmitpal/C-Programing-Codes.git
cd C-Programing-Codes
```

Compile and run any file with `gcc`:

```bash
gcc filename.c -o filename
./filename
```

## 🤖 How the auto-update works

A workflow at `.github/workflows/update-readme.yml` runs on every push to `main`. It scans the repo for source files, rebuilds the list between the `FILE-LIST` markers above, and commits the updated `README.md` back automatically. You don't need to do anything — just push your code as usual.
